# FinSight AI Landing Page (Draft)

Draft, editable landing page template for a Computer Engineering graduation project focused on:

- Artificial Intelligence
- Financial Sentiment Analysis
- Market Prediction

## Stack

- React (Vite)
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Site adresi: **https://bil-495-496-graduation-project.github.io/landing-page/**

`main` branch'e push edildiğinde GitHub Actions otomatik olarak deploy eder.

### İlk kurulum (repo ayarları)

1. GitHub'da repo → **Settings** → **Pages**
2. **Build and deployment** → Source: **GitHub Actions**
3. Org seviyesinde Pages kapalıysa, organizasyon yöneticisinden etkinleştirmesini isteyin

### Manuel deploy

Actions sekmesinden **Deploy to GitHub Pages** workflow'unu **Run workflow** ile çalıştırabilirsiniz.
